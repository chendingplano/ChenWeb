Recommendation

Why Option B

  • Matches the current home3/knowledge menu model with the smallest conceptual jump.
  • Lets Summary Graph and Summary Tree become distinct, testable pages while sharing services and visual language.
  • Supports phased delivery: mocked editing actions first, then live add/edit/delete, then merge/split.
