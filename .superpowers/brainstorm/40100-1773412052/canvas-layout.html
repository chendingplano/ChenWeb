A — Integrated in home3 shell

Reuses home3's nav-rail (adds Tools → Flow item). Left panel = Node Palette, canvas = main content area, right shelf = Properties. Fits natively into the existing 3-panel layout.

Pros

  • Consistent UI
  • Less code to write
  • Rail nav stays usable

Cons

  • Canvas space is limited
  • Shelf may feel cramped for complex properties

B — Full-screen canvas mode

When Tools → Flow is selected, the canvas takes over the entire content area. The nav-rail collapses to icon-only. Node Palette floats or docks left. Properties panel slides in from right on node selection.

Pros

  • Maximum canvas space
  • Immersive editing experience

Cons

  • More state to manage
  • Lose context of nav

C — Flow manager + dedicated editor

Tools → Flow shows a "My Flows" list in home3. Clicking a flow opens a dedicated full-screen canvas editor page (new route like /flow-editor/[id]). Supports multiple flows.

Pros

  • Supports multiple flows
  • Maximum canvas real estate
  • Clean separation

Cons

  • More routes/pages
  • Loses home3 nav context
