Flow Picker behaviour

  • On canvas open: if user has a default flow → load it immediately, skip picker. Otherwise → show picker.
  • Tabs: My Flows (owned), Shared Flows (shared by others), Templates.
  • Card thumbnail: mini SVG preview of the flow graph stored in the flow record.
  • Right-click / context menu on card: Open · Set as default · Save as template · Duplicate · Delete.
  • Toolbar flow-name dropdown: re-opens picker to switch flows without leaving the canvas.
  • Templates tab: same card layout, but cards show a "Use template" button — creates a new flow forked from the template.
