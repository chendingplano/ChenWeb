Frontend — Svelte components

web/src/lib/components/shared-ui/
canvas-01.svelte — main entry point; mounts the full-screen overlay
Holds all canvas state: active flow, nodes/edges, selected node, undo stack, palette/properties visibility

canvas/

FlowPicker.svelte — modal: My Flows / Shared / Templates tabs, flow cards, fork/open actions
NodePalette.svelte — dockable/floatable left panel; grouped node list; drag to canvas
PropertiesPanel.svelte — right panel; renders attribute editors for the selected node type
FlowCard.svelte — reusable card used in FlowPicker (thumbnail, name, meta, context menu)

Key state inside canvas-01.svelte (Svelte 5 runes)

activeFlow = $state<Flow | null>(null)
nodes = $state<Node[]>([])
edges = $state<Edge[]>([])
selectedNodeId = $state<string | null>(null)
showPicker = $state(false)
paletteFloating = $state(false) — true when palette is dragged out
undoStack / redoStack = $state<Snapshot[]>([]) — JSON snapshots of nodes+edges
isDirty = $derived(/* compare to last saved snapshot */)
