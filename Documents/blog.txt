三、办公四件套的核心思想
第2篇我们讲过，Skill有两种模式：

纯SKILL.md模式：所有逻辑写在文档里，每次都吃Token
SKILL.md + 脚本模式：文档只写流程，复杂逻辑固化到脚本
办公四件套全部采用第二种——"精简SKILL.md + 脚本"模式。

为什么？因为办公文档处理涉及复杂的文件格式（OOXML、PDF结构），用脚本处理更稳定。

# Word 文档创建、编辑和分析

## 概述
用户可能要求你创建、编辑或分析 .docx 文件的内容。
.docx 文件本质上是一个包含 XML 文件和其他资源的 ZIP 压缩包。

## 工作流决策树

### 读取/分析内容
使用下方的"文本提取"或"原始 XML 访问"章节

### 创建新文档
使用"创建新 Word 文档"工作流

### 编辑现有文档
- **自己的文档 + 简单修改** → 使用"基础 OOXML 编辑"工作流
- **他人的文档** → 使用"修订工作流"（推荐默认）
- **法律、学术、商业文档** → 使用"修订工作流"（必需）

## 读取和分析内容

### 文本提取
使用 pandoc 将文档转换为 markdown：
> pandoc --track-changes=all path-to-file.docx -o output.md

### 原始 XML 访问
解压文档读取原始 XML：
> python ooxml/scripts/unpack.py <office_file> <output_dir>

关键文件结构：
* word/document.xml - 主文档内容
* word/comments.xml - 批注
* word/media/ - 嵌入的图片和媒体

## 创建新 Word 文档

### 工作流
1. **必须** - 完整阅读 docx-js.md（~500行）
2. 使用 Document、Paragraph、TextRun 组件创建 JS 文件
3. 使用 Packer.toBuffer() 导出为 .docx

## 编辑现有 Word 文档

### 工作流
1. **必须** - 完整阅读 ooxml.md（~600行）
2. 解压文档: python ooxml/scripts/unpack.py <file> <dir>
3. 使用 Document 库创建并运行 Python 脚本
4. 打包文档: python ooxml/scripts/pack.py <dir> <file>

## 修订工作流（专业场景）

用于法律、学术、商业文档的修订追踪：
1. 获取 markdown 表示
2. 识别和分组更改
3. 解压文档，记录建议的 RSID
4. 分批实现更改（每批3-10个）
5. 打包文档
6. 最终验证

## 依赖
- pandoc: 用于文本提取
- docx: 用于创建新文档（npm install -g docx）
- LibreOffice: 用于 PDF 转换

# Excel 创建、编辑和分析

## 输出要求

### 零公式错误
每个 Excel 必须交付时确保零公式错误（#REF!、#DIV/0!、#VALUE!、#N/A、#NAME?）

### 财务模型颜色编码标准
- **蓝色文字**: 硬编码输入（用户会更改的假设值）
- **黑色文字**: 所有公式和计算
- **绿色文字**: 从其他工作表引用的链接
- **红色文字**: 外部链接

## 关键：使用公式，而非硬编码值

### ❌ 错误 - 硬编码计算值
total = df['Sales'].sum()
sheet['B10'] = total  # 硬编码 5000

### ✅ 正确 - 使用 Excel 公式
sheet['B10'] = '=SUM(B2:B9)'

## 常见工作流
1. **选择工具**: pandas 用于数据，openpyxl 用于公式/格式
2. **创建/加载**: 创建新工作簿或加载现有文件
3. **修改**: 添加/编辑数据、公式和格式
4. **保存**: 写入文件
5. **重算公式（必须）**: python recalc.py output.xlsx
6. **验证并修复错误**: 检查 error_summary 获取具体错误

## 重算公式
openpyxl 创建的 Excel 包含公式字符串但没有计算值。
使用 recalc.py 重算：
> python recalc.py <excel文件> [超时秒数]

脚本功能：
- 自动设置 LibreOffice 宏
- 重算所有工作表中的所有公式
- 扫描所有单元格查找 Excel 错误
- 返回包含详细错误位置的 JSON
5.3 为什么强调公式？
用公式的Excel是活的：改一个数，全表联动重算
硬编码的Excel是死的：改了源数据，结果不变
recalc.py 的作用：

openpyxl 创建的 Excel 只有公式字符串，没有计算值。打开时需要 Excel/LibreOffice 计算一次。

recalc.py 通过调用 LibreOffice 自动完成这个计算过程，并检测公式错误。

5.5 recalc.py 核心实现
def recalc(filename, timeout=30):
    """
    使用 LibreOffice 重算 Excel 公式并检测错误
    """
    # 1. 设置 LibreOffice 宏（首次运行）
    setup_libreoffice_macro()

    # 2. 调用 LibreOffice 重算
    cmd = [
        'soffice', '--headless', '--norestore',
        'vnd.sun.star.script:Standard.Module1.RecalculateAndSave?...',
        abs_path
    ]
    subprocess.run(cmd, capture_output=True)

    # 3. 扫描所有单元格查找错误
    wb = load_workbook(filename, data_only=True)
    excel_errors = ['#VALUE!', '#DIV/0!', '#REF!', '#NAME?', '#NULL!', '#NUM!', '#N/A']

    for sheet_name in wb.sheetnames:
        ws = wb[sheet_name]
        for row in ws.iter_rows():
            for cell in row:
                for err in excel_errors:
                    if err in str(cell.value):
                        # 记录错误位置
                        error_details[err].append(f"{sheet_name}!{cell.coordinate}")

    # 4. 返回结果
    return {
        'status': 'success' if total_errors == 0 else 'errors_found',
        'total_errors': total_errors,
        'error_summary': {...}
    }

# PPT 创建、编辑和分析

## 概述
用户可能要求你创建、编辑或分析 .pptx 文件的内容。.pptx 文件本质上是一个包含 XML 文件的 ZIP 压缩包。

## 读取和分析内容

### 文本提取
> python -m markitdown path-to-file.pptx

### 原始 XML 访问
> python ooxml/scripts/unpack.py <office_file> <output_dir>

## 创建新 PPT（不使用模板）

使用 html2pptx 工作流：

### 设计原则
1. **考虑主题**: 什么语气、行业、情绪？
2. **检查品牌**: 考虑品牌颜色和身份
3. **将配色与内容匹配**
4. **只使用网页安全字体**: Arial、Helvetica、Times New Roman...

### 工作流
1. **必须** - 完整阅读 html2pptx.md
2. 为每张幻灯片创建 HTML 文件（720pt × 405pt for 16:9）
3. 使用 html2pptx.js 转换为 PowerPoint
4. **视觉验证**: 生成缩略图检查布局
   > python scripts/thumbnail.py output.pptx

### 工作流
1. 提取模板文本并创建缩略图网格
2. 分析模板并保存清单到文件

4. 使用 rearrange.py 复制、重排幻灯片

7.4 thumbnail.py 核心实现
生成PPT缩略图网格是视觉验证的关键：

def main():
    # 1. 将PPT转换为PDF
    subprocess.run(['soffice', '--headless', '--convert-to', 'pdf', pptx_path])

    # 2. 将PDF转换为图片
    subprocess.run(['pdftoppm', '-jpeg', '-r', '100', pdf_path, 'slide'])

    # 3. 创建网格布局
    grid = Image.new("RGB", (grid_w, grid_h), "white")

    for i, img_path in enumerate(slide_images):
        # 添加编号标签
        draw.text((x, y), str(i), fill="black", font=font)

        # 粘贴缩略图
        with Image.open(img_path) as img:
            img.thumbnail((width, height))
            grid.paste(img, (tx, ty))

    # 4. 保存网格图
    grid.save("thumbnails.jpg", quality=95)
